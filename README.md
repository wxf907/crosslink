# CrossLink 跨端互传

同一局域网内，手机与电脑、电脑与电脑之间**零流量**互传文件、图片与文字。
不走云端、不需要服务器、不需要注册账号——输入相同的账号密码即自动组网。

## 功能一览

- **自动发现设备**：同一账号、同一局域网内自动互相出现，无需配置 IP
- **手动连接兜底**：跨网段或路由器过滤广播时，可手动输入对方 IP 直连
- **拖拽发送**：电脑端把文件或选中文字拖进窗口即可发送
- **粘贴发送**：电脑端右键或 Ctrl+V，剪贴板里是文件/图片/文字都能直接发出
- **截图速传**：电脑端全局快捷键（默认 Alt+A）截图后一键发给手机
- **拍照与相册**：手机端可拍照发送或从相册选择，支持原图或压缩
- **自动保存到公共目录**：手机端收到的图片进相册、文件进下载目录，
  任何文件管理器都能看到（无需授予任何存储权限）
- **真实在线状态**：基于持久连接与应用层心跳，不会"显示在线却发不出去"
- **断线自动重连**：切换网络、休眠唤醒后自动恢复，无需重启程序
- **后台保活**：安卓常驻通知维持连接，锁屏不掉线

## 下载安装

前往 [Releases](../../releases) 下载对应平台的最新文件：

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows | `CrossLink-Setup-<版本>.exe` | 安装包，双击安装（支持 Win10/11 x64） |
| Android (64 位) | `CrossLink-<版本>.apk` | 2019 年之后的绝大多数手机 |

> 自 2.2.0 起不再提供 32 位（armeabi-v7a）安装包。若确需在很旧的设备上使用，
> 可提 issue 说明机型，会单独构建。
>
> 安卓安装时如提示"未知来源"，请在系统设置中允许安装。

## 使用方法

1. **电脑端**：安装后打开，设置账号密码与设备名（首次运行若弹防火墙授权，请点"允许"）
2. **手机端**：安装后打开，输入**相同**的账号密码登录
3. **传输**：在设备列表选中对端，然后拖文件 / 粘贴 / 输入文字发送
4. 手机端点输入栏「+」可拍照或从相册选图

注意：CrossLink 的"账号"是**组网凭证**而非身份账号——所有输入相同账号密码的设备
会互相发现并组成一个群组。它适合个人自己的多台设备，或一个小团队内部使用。

## 升级与签名

- 自 2.2.0 起使用**固定的正式签名**发布，后续版本可直接覆盖安装，聊天记录与设置保留。
- **例外**：若你从 2.1.x 或更早升级到 2.2.0，由于签名由调试证书换成了正式证书，
  需要先卸载再安装（这是唯一一次）。

## 已知问题与修正说明

早期版本说明中曾把两类现象归因错误，此处更正，避免误导：

- **部分手机安装后白屏/闪退**：根因是**安装包内容缺失**（分别缺少渲染所需的原生库、
  以及 Dart 业务代码 `libapp.so`），**不是** GPU 驱动或 Impeller 渲染引擎问题。
  当时"关闭 Impeller 后包体积从 26MB 降到 15MB"实际是丢了业务代码的表现。
  2.2.0 起发版加入强制完整性校验（原生库、资源、架构、版本号逐项核对），
  校验不通过不产出交付物。
- **"无法覆盖安装 / 提示已有高版本"**：根因是 versionCode 出现倒退，与代码无关。
  现已固定编号规则并纳入发版检查。

## 从源码构建

```bash
flutter pub get
flutter build windows --release                 # Windows
flutter build apk --release --split-per-abi     # Android
```

发布建议统一使用 `tools/release.ps1`：它会依次做版本一致性检查、静态分析、
单元测试、构建，并对产物施加完整性门禁（原生库、资源、架构唯一性、体积区间、
versionCode 可覆盖性），任一项不通过即中止，不产出交付物。

**签名**：把 `android/key.properties.example` 复制为 `android/key.properties`
并填入你自己的密钥信息，即可产出正式签名的 release 包；不配置时自动回退调试签名
（能构建，但产出的包无法覆盖安装已发布的正式版本）。
密钥文件与 `key.properties` 均已在 `.gitignore` 中排除，请勿提交。
